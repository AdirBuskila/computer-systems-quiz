# אלגברה בוליאנית

> 🔑 **בשורה אחת:** כמעט כל שאלה היא "איזו שקילות לא נכונה". שתי דרכים בטוחות: **טבלת אמת** (לפי כל הצירופים) או **פתיחת ה-XOR** ל-AND/OR/NOT ופישוט. XOR ו-XNOR הם הכי הרבה מלכודות.

## מה המבחן שואל

שאלה ראשונה כמעט בכל מבחן: ששה ביטויים, אחד לא נכון. הביטויים בנויים בעיקר מ-XOR עם משלימים (`25B-A-Q1`). לפעמים שאלה על קבוצת שערים שלמה, או פונקציה כתובה במשוואה ויש לפשט או לזהות ערך.

## זהויות (דף הנוסחאות)

| זהות | הערה |
|---|---|
| $X \oplus 0 = X$, $X \oplus 1 = \bar X$ | XOR עם 1 הופך |
| $X \oplus X = 0$, $X \oplus \bar X = 1$ | |
| $X\oplus Y = Y \oplus X$ | קומוטטיבי |
| $(X\oplus Y)\oplus Z = X\oplus(Y\oplus Z)$ | אסוציאטיבי |
| $X\oplus Y = X\bar Y + \bar X Y$ | פתיחה |
| $\overline{X\oplus Y} = X\oplus\bar Y = \bar X\oplus Y = XY + \bar X\bar Y$ | שלילת XOR: מספיק להפוך **אחד** האופרנדים |

זהויות בסיסיות נוספות שמותר להשתמש בהן:

- דה מורגן: $\overline{A+B}=\bar A\bar B$ ו-$\overline{AB}=\bar A+\bar B$.
- בליעה: $A + AB = A$ ו-$A(A+B)=A$.
- $A + \bar A B = A + B$.
- קונסנסוס: $AB + \bar A C + BC = AB + \bar A C$.
- חוק הפילוג מתקיים בשני הכיוונים: $A+BC=(A+B)(A+C)$.

## מתכון: בדיקת שקילות

1. אם יש עד 3 משתנים, בונים טבלת אמת ל-8 שורות ומשווים את שני הצדדים. זו הדרך הבטוחה.
2. אחרת פותחים כל $\oplus$ לפי $X\oplus Y = X\bar Y+\bar X Y$, מפעילים דה מורגן ומפשטים.
3. כדי לפסול אפשרות מספיק למצוא **הצבה אחת** שבה הצדדים שונים. מנסים קודם $0,0,0$ ו-$1,1,1$ ואחר כך הצבות מעורבות.
4. לפני העבודה, משלימים מקבצים: $\bar A\oplus B$ שווה ל-$\overline{A\oplus B}$.

## דוגמה

האם $\overline{A\oplus B} = \bar A\oplus B$? בודקים בארבע השורות. $(A,B)=(0,0)$: משמאל $\overline{0}=1$, מימין $1\oplus 0=1$. $(1,0)$: $\overline{1}=0$ מול $0\oplus 0=0$. $(0,1)$: $\overline{1}=0$ מול $1\oplus 1=0$. $(1,1)$: $\overline{0}=1$ מול $0\oplus 1=1$. כל השורות שוות, ולכן הטענה נכונה.

## מלכודות

> 🪤 **$\overline{A\oplus B} \ne \bar A\oplus\bar B$.** שני משלימים מבטלים זה את זה: $\bar A\oplus\bar B = A\oplus B$.

> 🪤 **XOR אינו נבלע.** $A + A\oplus B$ אינו $A$. בליעה חלה רק על AND ו-OR.

> ⚠️ **סדר הפעולות:** AND קודם ל-OR. כשמערבבים $\oplus$ עם AND/OR, הסוגריים במבחן הם שקובעים: קראו אותם בקפידה.

> ⚠️ **שלילה על הביטוי כולו או על משתנה בלבד:** קו על $A\oplus B$ שונה מקו על $A$ בלבד.

> 💡 הקשר ל-NAND/NOR ולבניית שערים מצוין ב-[[logic_gates]].
