# אסמבלי MIPS ותרגום ל-C

> 🔑 **בשורה אחת:** תרגום בין C לאסמבלי מבוסס על ארבעה דפוסים: **גישה למערך** (כתובת = בסיס + 4 כפול אינדקס), **תנאי** (ההיפוך של התנאי הוא ההסתעפות), **לולאה** (תווית בראש + קפיצה חוזרת), **מעקב** (טבלת ערכים לפי איטרציות).

## מה המבחן שואל

- מה הערך ההתחלתי באוגר, כשיודעים מה בסוף (`25B-A-Q10`: לולאת מסכה).
- מהו התרגום הנכון של שורת C או קטע C (`25B-A-Q13`, `25B-A-Q20`).
- מה הפונקציה מחשבת, וכמה פקודות מתבצעות.

## מתכונים

**גישה למערך מילים.** `array[i]` נמצא בכתובת $array + 4i$.
- הכפלה ב-4 על ידי חיבור עצמי כפול: `add t,i,i` ואז `add t,t,t`. אם הדף לא כולל `sll`, זו הדרך.
- אחר כך `add t,t,base` ו-`lw`/`sw` עם offset 0.
- `array[4*i]` הוא $array + 16i$: ארבע הכפלות ב-2.

**תנאי.** `if (a > b) { body }`: הפוך את התנאי וקפוץ מעל הגוף.
```asm
slt  $1, $b, $a        # 1 אם a > b
beq  $1, $0, skip      # אם לא, מדלגים
# body
skip:
```
`a == b` הוא `bne a,b,skip`, `a != b` הוא `beq a,b,skip`. `a < b`: `slt` ישירות.

**לולאה.** תווית בראש עם בדיקת יציאה, גוף, קפיצה חזרה.
```asm
loop: beq  $3, $5, done   # i == n ?
      # body
      addi $3, $3, 1
      beq  $0, $0, loop    # קפיצה בלתי מותנית
done:
```

**מצביעים.** `ptr = &array[0]` הוא `add ptr, base, zero`. `*ptr` הוא `lw x,0(ptr)`. `ptr++` על מערך מילים הוא `addi ptr,ptr,4`.

**מעקב.**
1. טבלה עם עמודה לכל אוגר ושורה לכל איטרציה.
2. מתחילים מערכים התחלתיים.
3. מבצעים פקודה אחר פקודה. הסתעפות שלא התקיימה נופלת לפקודה הבאה.
4. מזהים את החוק הכללי ("סופר ביטים אפסים", "מחשב מקסימום") וקובעים תוצאה.

**מסכה.** אוגר מסכה מתחיל ב-1 ומוזז שמאלה בכל סיבוב (`add m,m,m`). `and t,m,x` בודק ביט אחד. אחרי 32 הזזות המסכה הופכת ל-0 והלולאה נגמרת. מונה שמקדמים רק כשהתוצאה 0 סופר את **האפסים** ולא את האחדות.

**ספירת פקודות.** פקודות בגוף כפול מספר איטרציות, ועוד פקודות אתחול, ועוד הבדיקה האחרונה שיוצאת מהלולאה.

**קריאה לפרוצדורה.** `jal label` שומר באוגר ra (31) את PC+4 וקופץ, `jr` על ra חוזר. ארגומנטים באוגרים a0-a3 (4-7), תוצאה ב-v0 (2).

## דוגמה

סכום מערך: אוגר 4 בסיס, אוגר 5 הגודל $n$, התוצאה באוגר 2.
```asm
      add  $2, $0, $0       # sum = 0
      add  $3, $0, $0       # i = 0
      add  $6, $4, $0       # ptr = array
loop: beq  $3, $5, done
      lw   $7, 0($6)
      add  $2, $2, $7
      addi $6, $6, 4
      addi $3, $3, 1
      beq  $0, $0, loop
done:
```
C מקביל: `for (i=0; i<n; i++) sum += array[i];`. מספר הפקודות שמתבצעות: $3 + 6n + 1 = 6n+4$ (שלוש לאתחול, שש בכל איטרציה, ועוד `beq` אחד ביציאה).

## מלכודות

> 🪤 **תנאי הפוך.** הסתעפות ב-`beq`/`bne` קופצת **מעל** הגוף כשהתנאי לא מתקיים. מי שמעתיק את התנאי כמו שהוא, מקבל תוצאה הפוכה.

> 🪤 **אינדקס מילים ולא בתים.** `lw` עם אינדקס בלי הכפלה ב-4 קורא כתובת לא מיושרת.

> ⚠️ **אוגר 0 הוא תמיד 0.** כתיבה אליו לא משנה. חיבור עם אוגר 0 משמש להעתקה.

> ⚠️ **כתובת הסתעפות יחסית ל-PC+4** (ראו [[mips_machine_code]]).

> ⚠️ **שמירת אוגרים.** בשאלות "אוגרים 4 ו-5 צריכים להישאר ללא שינוי" לא כותבים אליהם, משתמשים בהעתקות.
